# RESPOND — Emergency Decision Assistant

It is a simple emergency guidance web app. It helps users quickly find basic step-by-step guidance for common emergency situations.

## 🚨 Problem

During emergencies, people can panic or waste time searching for the right information. RESPOND presents essential actions in a simple and easy-to-follow format.

## 💡 How It Works

```text
Home
 ↓
Select Emergency
 ↓
View Guidance
 ↓
Step-by-Step Actions
 ↓
Start Again
```

### Current Scenarios

* 🚗 Road Accident
* 🩸 Severe Bleeding
* 😵 Unconscious Person
* 🔥 Fire

## 🛠️ Tech Stack

* **HTML** — page structure
* **CSS** — responsive and vibrant UI
* **JavaScript** — application logic
* **React** — interactive interface

## 🎨 Design

The interface uses a **dark, vibrant theme** with blue, cyan and purple accents, responsive emergency cards, hover effects and clear step-by-step instructions.

## 🚀 Future Scope

* Yes/No decision-based guidance
* Progress indicator
* Emergency history using `localStorage`
* Accessibility improvements
* Offline emergency information
* More verified emergency scenarios
